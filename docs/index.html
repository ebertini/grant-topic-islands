Grant Topic Islands

A visual analysis of a collection of research-grant abstracts. Keyphrases were extracted per grant, organized into a three-level topic hierarchy, and mapped to the documents they cover. Two views of the same structure:

Topic Islands →

A semantic map of topics as labeled keyphrase clusters. Click a topic to drill into its subtopics; click a keyphrase to read the grants that mention it, with the term highlighted in each abstract.

Topic Cards →

Every top-level topic as a card, with its subtopics, document-coverage bars, and expandable keyphrases. Sortable, filterable by funder.
Built from an offline Python pipeline (research-grant filtering, keyphrase extraction, hierarchical clustering, and topic labeling). Static site — no server required.
